## AzLauncher
- AzLauncher is a Minecraft Launcher

## Ulix
- Ulix is a **Graphics User Interface Library** for AzLauncher
- Built with Vulkan, with **High Rendering Capability**, and **High Ceiling**, ensure smooth performance during runtime.

## Platform
- Supported OS: `Windows`
- Minimum supported Windows version: `Windows 7 SP1 x64`
- Graphics API: `Vulkan 1.0+`
